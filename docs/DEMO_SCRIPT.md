# Live Demo Script

## Before judges arrive
- Run `streamlit run app.py`.
- Keep Demo Mode on.
- Click Run Reconciliation once.
- Keep the browser on the dashboard.

## On stage
1. "This is GST Reconcile."
2. Point to the four metrics.
3. "But our key output is not the match percentage — it is the supplier chase queue."
4. Select a HIGH/MEDIUM exception.
5. Point to supplier, invoice, exception, exposure and recommended action.
6. Click Generate Supplier Follow-up.
7. Show the draft.
8. Download CSV only if time permits.

## Backup
If upload fails or time is short, keep demo data enabled. The product's core workflow is fully reproducible offline.
